L-IA: Asistente Híbrido Local/Nube

Asistente de escritorio desarrollado en Python para entorno Windows. Integra un enrutador inteligente de consultas, conciencia del entorno de trabajo (archivos y ventanas activas) y un sistema de memoria técnica a largo plazo basado en RAG con modelos locales. Su interfaz evolucionó de Tkinter a un HUD reactivo con Tauri + React sobre un backend FastAPI.

Python 3.11 ChromaDB Ollama (Gemma 2) Edge-TTS Tauri + React FastAPI

De Tkinter a un HUD Reactivo

La interfaz evolucionó de una ventana estática a un entorno dinámico construido con Tauri v2 y React, respaldado por un backend asíncrono en FastAPI. Logramos reducir el TTFT (tiempo de latencia) a 0.47s con streaming SSE y mantener un consumo de 0 MB de VRAM en el renderizado visual, protegiendo los recursos para la inferencia local.

Resolución de Problemas Críticos

Errores documentados y solucionados durante el desarrollo arquitectónico de las fases 3 a la 8.

ISSUE // 01
El "Incidente de las Descargas"

Un script de pruebas borró accidentalmente 5 GB de instaladores locales. Solucionado implementando el Tool Manager como embudo obligatorio de Nivel 2 con confirmación humana explícita.

Mitigado
ISSUE // 02
Amnesia Post-Lectura

El modelo perdía el contexto en preguntas de seguimiento. Resuelto con la persistencia del Workspace Activo en SQLite y la inyección silenciosa de un micro-resumen técnico en el prompt.

Resuelto
ISSUE // 03
Error 400 en Gemini SDK

Conflicto al combinar búsquedas web con herramientas locales y esquemas de diccionarios planos. Corregido refactorizando las funciones hacia objetos ejecutables tipados (callables) nativos de Python.

Resuelto
ISSUE // 04
Excepción en Ingesta RAG

El fragmentador colapsaba al recibir diccionarios en lugar de texto plano durante la vectorización inicial. Solucionado integrando un parser defensivo en la rutina de ingesta.

Resuelto
ISSUE // 05
Saturación del Búfer Typewriter

El efecto de escritura colapsaba al animar reportes extensos de Git o RAG. Se bifurcó el renderizado: los bloques de más de 50 caracteres se inyectan de una vez y el flujo en vivo conserva la animación.

Resuelto
ISSUE // 06
Error 404 en la Nube Pro

Los identificadores de modelo quedaron obsoletos en la API v1beta. Se actualizó a gemini-3.1-pro-preview y se añadió un mensaje keep-alive para que el canal SSE no se cierre durante la llamada síncrona.

Resuelto
ISSUE // 07
Colapso de la Interfaz 2.5D

Pantalla en blanco causada por variables huérfanas y llamadas a componentes inexistentes dentro del ciclo de vida del estado. Se eliminaron las referencias y se restableció el renderizado.

Resuelto
ISSUE // 08
Rutas Perdidas tras un Backup

Restaurar un respaldo de api.py hizo desaparecer los endpoints PUT y DELETE de sesiones. Se restauraron y se adoptó la práctica de validar el listado de rutas tras cada restauración.

Resuelto
