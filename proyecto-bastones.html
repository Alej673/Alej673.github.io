Full-Stack Web Development

ERP Operativo & Plataforma BTO

Sistema integral para manufactura artesanal que conecta la captación comercial web (Built-to-Order) con un núcleo ERP. Arquitectura basada en 'doble perímetro', transacciones ACID, motor de costeo reactivo y gestión tolerante a fallos.

Laravel 13 PHP 8 MySQL (InnoDB) JS (ES6) / Vite Bootstrap 5

Buzón BTO y Aislamiento

Recepción asíncrona de solicitudes web bajo un principio de "doble perímetro", aislando el motor de costos. Incluye integración con API de WhatsApp sanitizada.

Doble Perímetro WhatsApp API

Motor Reactivo (Cotizador)

Calculadora de producción (JS ES6) con búsqueda asíncrona (Select2). Fracciona costos en tiempo real y ejecuta transacciones ACID (DB::beginTransaction) al guardar.

AJAX / Select2 Transacciones ACID

Inventario SPA y Traductor

Kardex gestionado sin recargas de página. Aplica un "Traductor Inverso" que convierte la unidad de presentación comercial a la unidad mínima de consumo en BD.

SPA-UX Soft Deletes

Despacho y Deuda de Inventario

Lógica de descuento de stock con búsqueda inteligente. Aplica una estrategia de "Soft Fail" permitiendo saldos negativos controlados para no detener la producción.

Resiliencia (Soft Fail) PDF en RAM

Dashboard y KPIs

Panel de control administrativo con cálculo de métricas financieras. Integra un centro de alertas asíncrono para sanear faltantes sin salir de la vista principal.
